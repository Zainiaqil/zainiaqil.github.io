PORTOFOLIO ZAINI - TEMA LIGHT BLUE
===================================

CARA MENJALANKAN
1. Ekstrak ZIP ini.
2. Buka folder portfolio-zaini.
3. Jalankan index.html di browser.
4. Jangan pisahkan index.html dari style.css, script.js, dan folder img.

STRUKTUR
- index.html : isi website dan teks profil/project.
- style.css  : warna, layout, ukuran, responsive, dan animasi.
- script.js  : switch bahasa, menu mobile, animasi scroll, tahun footer.
- img/       : foto profil dan sertifikat.

CARA EDIT DENGAN PENANDA #
Buka index.html di VS Code lalu tekan Ctrl + F.
Cari penanda seperti:
- # 01 - NAVBAR
- # 02.1 - HERO / PROFIL UTAMA
- # 02.2 - ABOUT / TENTANG SAYA
- # 02.3 - SKILLS / KEAHLIAN
- # PROJECT 1
- # PROJECT 2
- # 02.5 - CERTIFICATES
- # 02.6 - CONTACT
- # 03 - FOOTER

MENGUBAH WARNA
Buka style.css dan cari:
# TEMA LIGHT BLUE - PUTIH & BIRU
Variabel warna utama:
--bg      : warna latar halaman
--surface : warna kartu
--text    : warna teks utama
--muted   : warna teks sekunder
--accent  : warna biru aksen

MENGUBAH PROFIL
Edit teks di bagian HERO dan ABOUT pada index.html.
Link belajar freeCodeCamp sudah diarahkan ke https://www.freecodecamp.org/.

MENGUBAH PROJECT
Cari # PROJECT 1 dan # PROJECT 2 di index.html.
Ganti judul, deskripsi, jenis project, dan tag teknologi.
Saat ini keduanya diberi label Dummy project agar tidak dikira project klien/produk live.

CATATAN
- Foto profil dan aset sertifikat bawaan ZIP dipertahankan.
- Sertifikat yang ditampilkan hanya file yang memang tersedia dalam ZIP.
- Nomor WhatsApp dan tautan GitHub bawaan tetap dipertahankan.
